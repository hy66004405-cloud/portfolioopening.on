# 체스 포트폴리오 완성본

이 폴더가 모든 작업의 기준 폴더입니다. 변경한 코드와 자산은 이곳에 직접 저장합니다.

## 실행

`포트폴리오 실행.command`를 더블클릭하세요. 이 노트북의 Python 3가 로컬 서버를 시작하고 브라우저를 엽니다.
사용 중에는 터미널 창을 열어 두세요. 종료는 Control+C입니다.
수동 실행: 이 폴더에서 `python3 launch.py`.
현재 작업 미리보기: http://127.0.0.1:8767/
대시보드 바로가기: http://127.0.0.1:8767/#design

## Design project — 대시보드

- ‘대외활동’ 폴더의 이미지 25개, 6개 프로젝트와 하위 폴더 순서를 유지합니다.
- 첫 화면에는 폴더별 작업 카드와 왼쪽 컬렉션 메뉴가 표시됩니다.
- 폴더 메뉴로 해당 영역에 이동하고, 각 카드 묶음을 화살표·드래그·트랙패드로 가로 탐색할 수 있습니다.
- 커서에 따라 카드가 은은하게 기울어지고 빛이 반응합니다.
- 카드를 누르면 거의 전체 화면 크기의 상세 패널이 열립니다.
- 큰 이미지 옆에 같은 프로젝트의 세부 이미지 목록이 표시됩니다.
- 완성본을 우선 표시하고, 제안 자료는 완성본의 부속 항목으로 구분합니다.
- 같은 위계의 이미지들은 동등하게 취급합니다.
- 세부 이미지 선택, 좌우 버튼·키보드 방향키·터치 스와이프를 지원합니다.
- 확대 이미지에 커서를 올리면 이미지가 미세하게 움직입니다.
- Close 또는 Escape로 확대 화면을 닫으면 대시보드의 기존 탐색 위치로 돌아갑니다.
- 원본 이미지는 Original 링크로 열 수 있습니다.

## Taste archive

Pinterest ‘그래픽 디자인’ 보드 이미지 18개를 원래 비율과 색상으로 전시합니다.
이미지를 누르면 확대 보기와 Pinterest 원본 링크가 표시됩니다.

## 체스 화면

- 정면에서 비스듬히 내려다보는 원근 카메라, 진회색 공간과 고전적인 서체
- c6 흑 나이트, c4 백 비숍, e5 흑 폰만 외곽 발광
- 나머지 기물·체스판 가장자리·배경의 은은한 블러
- 확대 화면은 큰 기물과 카테고리 제목만 표시
- 기물 호버 반응, 기물 또는 제목 클릭으로 컬렉션 진입
- 빈 배경 클릭으로 오프닝 복귀
- 체스 기물의 드래그·휠 회전은 제거된 상태

Experiment는 예시 콘텐츠입니다.

## 파일 안내

- `app.js`: 체스 장면, 카메라, 인터랙션, 컬렉션 연결
- `models.js`, `selective-blur.js`: 3D 모델과 선택적 블러
- `design-gallery.js`, `design-gallery.css`: 대시보드와 확대 패널
- `design-projects.js`, `design-source-manifest.json`: 프로젝트·이미지 분류
- `assets/design/originals/`: 원본 이미지 복사본 25개
- `assets/design/previews/`: 웹용 미리보기 25개
- `taste-images.js`, `assets/taste/`: Pinterest 이미지 18개
- `tools/import_design.py`: 로컬 폴더에서 이미지와 분류를 가져오는 도구

원본 ‘대외활동’ 폴더는 변경하지 않았습니다. 전시에 필요한 이미지와 라이브러리가 모두 이 폴더에 포함됩니다.
